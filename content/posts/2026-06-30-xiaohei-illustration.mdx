最近我在 GitHub 上看到一个爆火的小黑，插画效果很好。你看左边是它的一个效果，它可以给你的文章插入一些有趣的小插画，让内容看起来没有那么干。

<img
  src="https://assets.01mvp.com/images/makerjackie/2026-06-30-xiaohei-illustration/article-v1/article-01-original-xiaohei.jpg?v=20260630-v1"
  alt="GitHub 爆火小黑插画效果"
  width={1600}
  height={1036}
/>

然后我就基于它，做了我自己的版本。我觉得效果也挺不错的，有我自己的形象，还有它插入到我知识库中的效果。

<img
  src="https://assets.01mvp.com/images/makerjackie/2026-06-30-xiaohei-illustration/article-v1/article-02-own-version.jpg?v=20260630-v1"
  alt="基于小黑做出的 01MVP 自己版本"
  width={1600}
  height={1036}
/>

那我来分享一下我是怎么做的。

我是直接把 GitHub 仓库给它，然后仿照它的风格，也是黑白极简。但是它原始的版本线条还是太细了，不够有视觉冲击力，所以让它改了一下，并且创建我们对应的 Skills。

<img
  src="https://assets.01mvp.com/images/makerjackie/2026-06-30-xiaohei-illustration/article-v1/article-03-line-weight.jpg?v=20260630-v1"
  alt="调整小黑插画线条和视觉冲击力"
  width={1600}
  height={1036}
/>

最重要的一点是，用 Imagegen 生成我们自己的形象。这是 Codex 自带的生成能力，然后它生成了这个效果。

<img
  src="https://assets.01mvp.com/images/makerjackie/2026-06-30-xiaohei-illustration/article-v1/article-04-imagegen-result.jpg?v=20260630-v1"
  alt="用 Imagegen 生成自己的 01MVP 小黑形象"
  width={1600}
  height={1036}
/>

这个效果就已经很好看了，基本上不需要调。它就很符合我们 01MVP 这种感觉：从 0 到 1 做出一个自己最小可行产品。

我后面也让它试了几个形象，但还是第一版本效果好。

但由于这个图片就是要放到网站上，所以我们要让它做一下图片压缩，并且把它上传到我们的对象存储桶中。这样用户就可以直接通过一个网址链接来访问这个图片。

<img
  src="https://assets.01mvp.com/images/makerjackie/2026-06-30-xiaohei-illustration/article-v1/article-05-r2-upload.jpg?v=20260630-v1"
  alt="压缩图片并上传到对象存储"
  width={1600}
  height={1036}
/>

这个风格定下来之后，就让它生成相关文章的一些配图。实际上我是直接 @ 了我代码仓库中的一些文档，让它生成我对应的文章配图。

那接下来，我就让它开多个 agent 去做这个事情。你看右边可以有很多 agent，它给我的文档生成了几十张配图。

<img
  src="https://assets.01mvp.com/images/makerjackie/2026-06-30-xiaohei-illustration/article-v1/article-06-multi-agent.jpg?v=20260630-v1"
  alt="多个 agent 并行生成文章配图"
  width={1600}
  height={1036}
/>
