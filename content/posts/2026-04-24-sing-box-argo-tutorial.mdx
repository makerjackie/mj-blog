## 实战步骤（10 分钟搞定）

### 1. 准备工作

你需要一台海外 VPS（推荐新加坡、香港等地区），SSH 连接进去。

（我买的是 腾讯云新加坡的服务器， 听 AI 说直连线路质量还行。然后查了一下，虽然理论上不能用于 vpn ， 可能会被识别到，但自建个人用应该风险较小，后面有问题我再更新文章）

首先更新下系统环境：

```bash
apt update -y && apt upgrade -y
```

### 2. 执行安装脚本

复制下面的命令并执行：

```bash
bash <(wget -qO- https://raw.githubusercontent.com/fscarmen/sing-box/main/sing-box.sh)
```

### 3. 关键配置选择

脚本运行后会进入交互式菜单，这里有几个坑需要注意：

- **协议选择**：选 **VLESS + Reality**。这是目前最稳的伪装协议。
- **Argo 中转**：**一定要选「是」**。这是解决直连卡顿的关键。它会自动帮你创建 Cloudflare 隧道，让流量走 CDN。如果没有开启这个，连接会很不稳定。
- **SNI 设置**：建议填一些大厂域名，比如 `www.microsoft.com` 或 `dl.google.com`。
- 其他选项：如果没有特殊需求，一路回车默认即可。

安装完成后，脚本会直接输出你的**订阅链接**和二维码。输入 `sb` 命令可以随时查看管理后台。

## 全平台客户端推荐（2026 最新版）

有了订阅链接，下一步就是选择好用的客户端。

### Mac：FlowZ (首选推荐)

这是目前 Mac 端最现代化的 sing-box 客户端，界面是简洁的 shadcn/ui 风格，资源占用极低。

- **下载**：[GitHub Releases](https://github.com/dododook/FlowZ/releases)
- **注意**：如果提示「已损坏」，终端执行 `xattr -cr /Applications/FlowZ.app` 即可。
- **使用**：Profiles -> New Subscription，粘贴你的订阅链接，开启 TUN 模式。

### iOS：Stash / Shadowrocket

- **Stash**：推荐使用。
- **Shadowrocket**：老牌王者，支持最全，适合小白。
- **免费首选**：**sing-box VT** (官方出品，App Store 搜索即可)。

### Windows：v2rayN

- **下载**：[GitHub Releases](https://github.com/2dust/v2rayN/releases)
- **使用**：直接导入订阅链接即可。

### Android：NekoBox

- **下载**：[GitHub Releases](https://github.com/MatsuriDayo/NekoBoxForAndroid/releases)
- **特点**：基于 sing-box 内核，完美支持 Reality 订阅。
