## 为什么需要中转站

在国内用海外 AI 模型，主要有几个门槛。

- 海外信用卡不好办
- 某些 API 域名被限，直连不稳定
- 很多账户有封号风险，特别是充值 $200 的 Claude Pro

中转站解决的就是这些问题。它帮你统一接海外 API，用国内支付方式充值，网络也做了优化。

但中转站的问题也很明显：**太多了**。

随便一搜就是几十家，价格、稳定性、客服质量参差不齐。踩坑的概率不低。

## CC Switch：一个工具管所有中转站

不管你选哪家中转站，最终落到操作上就是一件事：**配 API Key 和 Endpoint**。

如果你的工作流涉及多个模型和多个 CLI 工具（Claude Code、Codex、Gemini CLI），来回改配置文件会很烦。

[CC Switch](https://github.com/farion1231/cc-switch) 是一个桌面端工具，用可视化界面管理这些配置，不需要手动改 JSON 或 `.env` 文件。

它有几个实用的功能。

- **50+ 内置提供商预设**，一键切换，拖拽排序
- **本地代理 + 自动故障转移**，一个挂了自动切到另一个
- **统一 MCP 面板**，跨应用同步
- **用量与费用追踪仪表盘**
- **Deep Link 导入**，别人分享的配置一键导入

这个项目是开源的，Tauri 2 + React + Rust 构建，数据存在本地的 SQLite 里。

它的赞助商列表里也有大量中转站，能看到很多圈内人实际在用的服务。
