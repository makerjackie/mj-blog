最近发自媒体，有一个很明显的感受：

**不是你想发什么，别人就会看什么。**

有时候我觉得自己写得挺真诚，内容也不差，但发出去就是没流量。阅读量很低，互动很少，甚至会怀疑是不是被限流了。

一开始我会有点不舒服。因为我以为自媒体是一个表达自己的地方。想到什么就写什么，做了什么就分享什么。

但后来慢慢发现，至少在大部分商业化内容平台上，自媒体并不是朋友圈。它更像是在开店。

标题是门头。封面是橱窗。开头是迎宾。正文是产品。评论区是互动现场。关注是用户愿意下次再来。

如果承认它是开店，很多事情反而更容易理解了。

## 后来我跟 AI 聊了聊这个困惑

我把这种"想表达自己但又想要流量"的拧巴感跟 AI 说了。它说了一段话让我印象很深：

**不是迎合观众，而是把自己真实想表达的东西，翻译成别人愿意接收的形式。**

迎合是：别人想听什么，我就说什么，哪怕我不相信。

翻译是：我依然说我相信的东西，但换一种别人更容易理解的方式说。

前者会消耗自己。后者是在训练表达能力。

这个区分挺有用的。它让我意识到，问题不在于"要不要妥协"，而在于"我到底想把这件事做成什么"。

## 把自由表达放在自己的地盘，把公共平台当作经营渠道

跟 AI 聊完我又想了很久，最后得出的结论是：**不要把两个目的混在一起。**

如果你只是想表达自己，那就好好表达自己，别太在意流量。发了没人看很正常，有人看是惊喜。

如果你想做影响力、想靠这个吃饭，那就认真开店。研究平台、研究算法、研究观众想看什么。这是商业行为，不是分享生活。

这两件事可以同时做，但不能在同一件事里做。

所以我现在的想法是：

**博客是我的自留地。** 想写什么就写什么，乱七八糟的思考、半成品想法、日常碎碎念，全都可以丢在这里。无所谓标题怎么样、有没有人看、别人怎么看。这本质上是一个互联网上的个人空间，我邀请你来看，但我不太在意你的看法。

**公众号、小红书、B 站、Twitter 这些平台，我把它们当店铺。** 主要目的是扩大影响力，所以大部分内容要对别人有用。当然也可以偶尔穿插一些个人表达，但控制频率，别把这两个目的搞混。

把自媒体想象成开店，一切就清晰了很多。

如果你觉得是在发朋友圈，你会纠结：怎么没人点赞？怎么没人互动？

但如果你觉得是在开店，你的问题会变成：这篇文章/这个视频，是不是哪里没照顾到顾客的感受？标题够不够吸引人？开头能不能留住人？内容有没有真的帮到人？

前者是情绪的纠结，后者是经营的优化。

## 不同平台是不同类型的店铺

想清楚之后，我发现不同的平台其实适合卖不同的"商品"。你的内容要在对的店铺里上架，才能卖得出去。

| 渠道            | 打算发什么                                                                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **个人博客**    | 一切。自由表达，想写什么写什么。半成品思考、日常碎碎念、长文沉淀、项目记录、个人感悟。不追热点，不研究算法，不在乎流量。这里是内容源頭。         |
| **Twitter / X** | 短平快。AI 工具技巧、产品进展、独立开发踩坑、小产品数据、一句话洞察、怎么用 AI 更快做出东西。                                                    |
| **小红书**      | 情绪和故事。自由职业之后的发现、做自媒体为什么会焦虑、普通人用 AI 做副业最容易踩什么坑、在某个城市做数字游民的一天、独立开发者的真实生活和困惑。 |
| **B 站**        | 教程沉淀。AI 编程从 0 到 1、01MVP 实战教程、用 AI 做一个小产品、Cursor / Claude Code / Cloudflare 实战、独立开发项目复盘。                       |
| **公众号**      | 完整文章。适合深度阅读的内容，个人品牌向的长文。                                                                                                 |

我的工作流也明确了：

**所有东西优先发在博客上，再挑合适的改到不同平台。**

先在博客里写最原始的版本，想怎么写就怎么写。然后再看看哪些内容值得传播，根据平台特性改写。

这样就不是被平台牵着走。而是我有自己的内容源头，再根据不同场景分发。

## 我不需要

我不需要说自己不相信的话。不需要追所有热点。不需要变成标题党。不需要为了流量把自己扭曲成另一个人。

但我需要知道：

读者为什么点进来？为什么划走？看完能得到什么？这个平台的人喜欢什么表达方式？

嗯，就是要意识到这一点吧。

既保留表达欲，有个地方可以记录真实的自己。又能给公众提供一些价值。两件事分清楚了，反而不拧巴了。

博客是家，可以乱。平台是店，要让人看懂。

这不是放弃真实。这是承认：表达是自己的事，传播是和别人共同完成的事。
