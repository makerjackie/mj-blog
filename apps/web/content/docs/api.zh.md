## API 用来做什么

API 只管理动态读者数据，不发布或编辑文章。

主要能力：

- 读者注册、登录和会话
- 提交评论与管理员审核
- 邮件和订阅偏好
- 管理员用户管理
- 通知与分析操作
- 登录管理员读取已编译的文章元数据

当前机器可读契约在 `/openapi.json`。

## 文章自动化

AI 或脚本应该直接修改 `content/posts/*.mdx`，验证仓库，再生成正常的代码变更。不要调用远程文章写接口，因为系统没有这个接口。

## 安全

读者和管理员操作使用 Better Auth 浏览器会话。后台接口要求管理员身份。系统有意不提供文章发布 Token 或跨域 Bearer 发布能力。
